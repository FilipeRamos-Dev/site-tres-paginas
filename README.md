# Atividade 01 do SENAI - HTML
## Descrição
>> A atividade 01 foi um exercício usando a tecnologia de Linguagem de Marcação HTML (Hyper Text Markup Language) com o objetivo de criar, pelo menos, 3 páginas com listas de itens de meu interesse utilizando o que foi trabalhado em sala de aula em uma página web.

## Conceitos
Trabalhamos diversos conceitos trabalhados em sala de aula como:
- Colocar links na página;
- Colocar imagens;
- Usar tags báscias como parágrafo, título e quebra de linha.

## Itens trabalhados
Os itens trabalhados foram:
- Elementos básicos da minha pessoa;
- Pessoas que eu tenho certa adimiração;
- Algumas universidade excelentes.

Em geral, foi uma boa aula introdutória de HTML.
